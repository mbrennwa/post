Post

A simple, native mail app for GNOME on Linux.

Post is free and open source. It uses your online accounts from GNOME Online Accounts and can also read local system mail. It is a focused desktop client — not a webmail wrapper and not a groupware suite.

Download Source on GitHub

What Post is

  • GTK4 / Adwaita mail client built on Evolution Data Server
  • Unified inbox, compose, search, and offline-friendly caching
  • Per-account sync control and optional send delay (undo-send grace period)
  • Packaged for Debian and Ubuntu as a .deb

What Post is not

  • Not a calendar, contacts, or tasks app
  • Not a replacement for your mail provider's web UI on other platforms
  • Not a proprietary sync service — your mail stays with your accounts and Camel cache

Install

On Debian 12+, Ubuntu 24.04+, or similar:

sudo apt install ./post_0.1.0_all.deb
post

Download the latest .deb from GitHub Releases, or build from source — see the README.
